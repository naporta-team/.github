## Sobre o projeto

O **NaPorta** é uma solução web e mobile desenvolvida para facilitar a solicitação e o gerenciamento de serviços em ambientes hoteleiros.

Por meio de um QR Code associado ao quarto, o hóspede acessa a plataforma, consulta o cardápio, realiza pedidos e acompanha o andamento até a entrega.

A aplicação também oferece um painel administrativo para gerenciamento de hóspedes, quartos, refeições, categorias e pedidos.

## Funcionalidades

- Acesso do hóspede por QR Code.
- Identificação automática do quarto e do solicitante.
- Consulta ao cardápio e realização de pedidos.
- Acompanhamento do status dos pedidos.
- Painel administrativo para gerenciamento da operação.
- Controle de usuários e permissões.
- Histórico e visualização de pedidos.
